# Student Result Processor

## Project Description
The Student Result Processor is a Python command-line
application that calculates student averages, assigns letter
grades, displays class statistics, and saves results to a CSV file.

## Features
- Add students and their subject scores.
- Calculate student averages automatically.
- Assign letter grades.
- Display the class average, highest result, and lowest result.
- Validate scores and other user inputs.
- Save and reload results using CSV file handling.

## Technologies Used
- Python 
- Visual Studio Code
- CSV file handling
- Python standard library

## Requirements
Install Python on your computer.

No additional Python packages are required.

## How to Run
1. Open the project folder in VS Code.
2. Open the integrated terminal.
3. Run the following command:

   python main.py
